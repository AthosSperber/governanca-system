# Governança System

Sistema mínimo de coordenação de agentes com protocolo explícito de mensagens e governança central.

## Como executar

1. Ative o ambiente virtual, se aplicável.
2. Execute o arquivo principal:
   - python main.py

## Estrutura

- core: protocolo e governança
- agents: agentes especializados
- applications/academia: aplicação de exemplo
- memory: estado persistente (placeholder)
