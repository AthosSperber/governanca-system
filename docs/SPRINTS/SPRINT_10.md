# SPRINT 10 — Public Demo & Consumption Layer

## Context

The repository has a formal Constitution and a stable protocol. The codebase already generates static HTML artifacts for the Academia reference domain via the visualization application.

## Goal

Provide a public demo and a consumption layer that lets a recruiter view the existing artifacts quickly, without changing runtime behavior or outputs.

## Work Done

- Added a static demo site folder with a neutral landing page and placeholder artifacts.
- Added a GitHub Pages workflow that runs the existing visualization pipeline and publishes the generated HTML artifacts.
- Updated README and documentation index with demo and adoption links.

## Pull Requests

## Result

Documentation-only and delivery-only changes. No runtime behavior change. No new metrics or reports. Demo publishes existing visualization artifacts only.

## Non-Goals

- No protocol or governance changes.
- No changes to the Constitution.
