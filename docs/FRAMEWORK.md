# Framework Orientation

## Purpose

This document states that the repository is a governance framework and that Academia is a reference domain used to demonstrate the framework. Constitutional authority is defined in `/constitution/GOVERNANCA_SYSTEM_CONSTITUTION.md`.

## What is the Core (Stable)

The core is the governance protocol and its controlled semantics. It includes Task, Action, and Report definitions, audit requirements, and the epistemic separation rules.

## What is a Reference Domain

A reference domain is a bounded, familiar context used to express the framework without redefining it. Academia serves as the current reference domain and does not redefine protocol or governance.

## What Changes When Adopting a New Domain

When adopting a new domain, the following are updated:

- Input data labels and field naming to match the new domain.
- Domain-facing labels used in documentation and visualization templates.
- Domain-specific folder naming within the applications directory.

## What Never Changes

The following remain stable across domains:

- Constitutional authority and governance constraints.
- Protocol semantics for Task, Action, and Report.
- Epistemic separation: Historical ≠ Simulation ≠ Visualization.
- Audit requirements and traceability expectations.

## Explicit Non-Goals

- No new metrics, reports, or outputs.
- No changes to runtime behavior or architecture.
- No changes to the Constitution.
