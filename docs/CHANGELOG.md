# Changelog

All notable governance milestones for governanca-system are documented here. This changelog focuses on versioned governance evolution rather than internal implementation details.

## v1.1

- Consolidated constitutional governance as the single source of truth.
- Reinforced separation between historical data, simulation, and visualization.
- Formalized traceability requirements across all artifacts.

## v1.0

- Established the initial governance framework for the Academia domain.
- Defined data contracts and baseline auditability rules.
- Set the non-decision posture for system outputs.
