# Academia Simulation (Project 2)

Esta aplicação cria um cenário hipotético separado do histórico da academia.

## Propósito

- Recalcular métricas em um dataset de simulação independente.
- Comparar valores históricos e simulados de forma numérica e descritiva.
- Manter separação explícita entre fatos históricos e hipótese estruturada.

## Limites de linguagem

- Não há decisão, recomendação ou interpretação.
- Nenhuma simulação vira histórico.

## Execução

```bash
python main.py run --app academia_simulation
```
