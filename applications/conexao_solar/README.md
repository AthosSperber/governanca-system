# Conexão Solar (Historical)

Domínio de referência mínimo para demonstrar métricas governadas em um contexto de landing page.
Os valores são **mock/demo** e não representam dados reais.

## Executar (local)

```bash
python main.py run --app conexao_solar
```

## Artefatos

- Snapshot governado em JSON: `output/governed_snapshot_conexao_solar.json`
- Log append-only: `memory/events.jsonl`

## Notas de governança

- Histórico ≠ simulação.
- Comparações são apenas numéricas.
- Este domínio existe apenas como referência controlada.
