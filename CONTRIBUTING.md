# Contributing

Obrigado por contribuir com o governanca-system.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Faça mudanças pequenas, explícitas e auditáveis.
4. Atualize a documentação quando necessário.
5. Abra um Pull Request descrevendo o motivo da mudança.

## Convenções

- Use mensagens de commit no padrão Conventional Commits.
- Mantenha o protocolo canônico estável.
- Não adicione lógica de decisão ou inferência.
